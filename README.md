# Élite Estates — site vitrine fictif

Projet universitaire : site statique responsive pour une agence immobilière de luxe fictive.

## Déploiement Netlify

1. Décompresser le dossier.
2. Aller sur Netlify et choisir l’option de déploiement manuel (« Deploy manually »).
3. Glisser-déposer le dossier du projet.
4. Aucun build command n’est nécessaire : `netlify.toml` indique que la racine du projet est le dossier publié.

## Fonctionnalités

- Accueil avec recherche rapide.
- Catalogue dynamique à partir de `js/properties.js`.
- Filtres pays, ville, type, prix, surface et chambres.
- Fiches détaillées via `property.html?id=...`.
- Formulaire de contact compatible Netlify Forms.
- Menu responsive mobile/tablette/ordinateur.
- Bandeau de consentement cookies et page dédiée.
- Pages CGU, CGV et confidentialité, explicitement fictives/pédagogiques.
- Mention « Images générées par l’IA » en pied de chaque page.
- Logo du projet placé dans `assets/logo.png`.

## Important

Les biens, prix, coordonnées et contenus commerciaux sont fictifs. Les images distantes sont utilisées uniquement comme illustrations du prototype. Les mentions légales sont des maquettes pédagogiques et doivent être remplacées/validées avant toute utilisation commerciale.
